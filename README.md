Blobbe is a platformer game built entirely with Pygame in Python. I created it by following a Pygame development tutorial to explore how Python can be leveraged in various ways. Solving the “stone spawn” logic and its running effect was one of the biggest challenges I overcame.

You can download the release from GitHub and run the Python file directly. At the moment it’s available only as a Pygame application; a web demo is still in the works.

AI assistance was used sparingly, only for tackling major problems, and never without a full understanding of the solutions.
